{%- comment -%} Comments for the mono theme via giscus, which keeps each thread in this repo's GitHub Discussions: no cookies, no trackers, no ads. Settings come from `giscus` in _config.yml, and the post layout only includes this once giscus.category_id is set. Each post maps to one discussion by its pathname. The widget's colours come from css/giscus-dark.css and css/giscus-light.css, which giscus loads by absolute URL, so a local build pulls the deployed copies. A theme flip posts the new stylesheet URL into the iframe. {%- endcomment -%}

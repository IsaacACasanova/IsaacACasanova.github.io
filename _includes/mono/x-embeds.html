{%- comment -%} X embeds follow the site theme. Any page with a
gets widgets.js loaded from here, so posts only need the blockquote. widgets.js bakes the theme into each iframe when it renders and swaps the blockquote out, so on a theme flip each embed is rebuilt from a saved copy of its blockquote and rendered again. While a card is loading its holder carries .is-loading, which mono.css draws as a placeholder; X's "rendered" event clears it. The placeholder is sized from the height this browser measured for the card last time (localStorage, keyed by status id and card width), else the desktop height in _data/x_embed_heights.yml, else the stylesheet's default. {%- endcomment -%}
